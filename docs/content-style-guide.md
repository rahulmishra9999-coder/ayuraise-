# AyuRaise Content Style Guide — "The Staircase"

_Extracted from Noom screenshots (July 2026) + our own findings. Every lesson, bot message,
and education card in the app follows this grammar. Content is judged RENDERED on a phone,
never as text in a file._

## The 8 rules

1. **One sentence = one paragraph.** 7–14 words per line, blank space between lines.
   Never a text block. If a thought needs two sentences, it's two lines.

2. **Lines chain like a staircase.** Each line picks up where the last ended:
   _Small goals → frequent wins → wins keep you motivated → motivation crushes more goals → "So let's do this, {name}."_

3. **Quiz options are bare.** 1–4 words, no emoji, no explanation inside the option.
   The teaching always waits for the next screen.

4. **The answer gets its own screen.** "You're right! 👍" or a neutral "Best answer: X" (never shame).
   Then exactly three beats:
   - a hook question ("But wait, aren't raisins just dried grapes?")
   - ONE number ("grapes are 81% water")
   - a cliffhanger ("We'll show you how to use this without giving up any food you love.")

5. **Concepts get names.** Caloric density. The 14-hour gap. Salad-first. The joy meal.
   A named idea is an owned idea. Introduce the name AFTER the aha, not before.

6. **Examples are always "If you…, try…"** Concrete situation → tiny move.
   _"If you're ordering takeout every day, try skipping one day a week."_
   Never abstract advice ("be mindful", "make better choices").

7. **Every lesson ends with "Putting it all together"** — 3 recap bullets,
   then a CTA into a real tool in the app (IF setup, diet plan, punch-in), not just praise.

8. **The user acts.** Type, pick, choose, set. A lesson where the user only reads is a failed lesson.

## Voice

- Second person, warm, direct. Use the user's first name where it lands ("So let's do this, Rahul").
- Numbers over adjectives: "81% water" beats "mostly water" beats "very hydrating".
- Desi kitchen context: methi water, katori, chilla, nariyal pani — the reader's real kitchen.
- Rhetorical hook questions are good: "But wait — aren't raisins just dried grapes?"
- No lecture words: avoid "should", "must", "remember that", "it is important to".

## Evidence base

Ground claims in NIDDK/NIH guidance where applicable:
- Safe pace: 5–10% of starting weight in 6 months.
- Activity: 150+ min/week moderate + strength 2×/week; 300 min/week for maintenance.
- Whole fruits over juices; added sugar < 10% of calories; sodium < 2,300 mg/day.
- Weekly self-weighing supports maintenance (not daily reactions).
- Fad red flags: "lose weight without diet or exercise", "eat as much as you want",
  "30 pounds in 30 days", spot reduction promises, fine-print asterisks.
